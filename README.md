AI Fake Job and Internship Detector

About the Project

The AI-Based Fake Job and Internship Offer Detection System is a machine learning project designed to identify potentially fake job and internship offers.

It helps users distinguish between genuine and fraudulent job postings using machine learning.

Project Files

- "AI_Fake_Job_Detector.ipynb" – Google Colab notebook containing the project code.
- "fake_job_model.pkl" – Trained machine learning model.
- "requirements.txt" – Required Python libraries.

Technologies Used

- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn
- Google Colab

How to Run

1. Clone or download this repository.
2. Install the required libraries.
3. Load the trained model.
4. Run the notebook to explore the project.

Project Type

Machine Learning / Artificial Intelligence
